# Security

Lodestone is an initial scaffold with no supported public release. Security reports
should refer to the latest code on `main` or the open bootstrap pull request.

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/lodestone-launcher-team/Lodestone/security/advisories/new).
Do not disclose vulnerabilities, credentials, or exploit details in public issues.

Include the affected component and commit, reproduction steps, likely impact,
and any suggested fix. Remove unrelated personal data and secrets.

The maintainer will review reports as availability permits. No response-time or
remediation guarantee is currently offered.
